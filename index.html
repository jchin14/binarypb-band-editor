Help

            
For more detailed instructions, visit the GitHub README.

            

                
Top bar

                
    
                    
  • Choose file — load a .binarypb file from your phone to start editing.
    • 
                    
  • Filter box — show only combos matching a band string, e.g. 1+3+7C+n78.
    • 
                    
  • Exact combo only — when checked, only combos with exactly those component carriers (no extras) match the filter.
    • 
                    
  • Clear — reset the band filter.
    • 
                    
  • Pagination / Per page — move between pages of combos and control how many are shown at once.
    • 
                    
  • Filename — sets the output filename used by the download buttons.
    • 
                    
  • ↓ .binarypb — download the edited file as a raw .binarypb.
    • 
                    
  • ↓ .zip — download a Magisk module zip that overlays the edited .binarypb on your phone.
    • 
                    
  • Clear session — wipes the locally stored session and reloads the page.
    • 
                    
  • View on GitHub — opens the project's source code repository.
    • 
                

            

            

                
Info bar

                
    
                    
  • Integrity field + Save/Restore — some binarypbs require an integrity value matching your phone's active file; Save/Restore store it in a cookie for next time.
    • 
                    
  • FeatureSets: Add — define custom downlink/uplink feature sets to reference from combos.
    • 
                    
  • FeatureSets: JSON — view/edit the raw feature set lists as JSON.
    • 
                    
  • Apply BM 65k patch — patches the bitmask so all bands are allowed (Pixel 7/8; always 0 on Pixel 9).
    • 
                    
  • Integrity ON/OFF — toggles whether the integrity field is present in the file.
    • 
                

            

            

                
Combo table

                
    
                    
  • + (Filtered Combos header) — adds a new combo to the first group.
    • 
                    
  • Select all filtered — selects every combo currently shown by the filter.
    • 
                    
  • Copy selected / Copy selected as text — duplicates selected combos, or copies them as portable text for pasting elsewhere.
    • 
                    
  • Import combo text — paste previously copied combo text into this profile.
    • 
                    
  • Remove selected / Remove all except selected — bulk delete combos.
    • 
                    
  • bcsNr / bcsIntraENDC / bcsEutra — per-group band combination set bitmasks.
    • 
                    
  • powerClass — 0 for default, 1 to force Power Class 2.
    • 
                    
  • intraEndc — intra-band EN-DC support flag for the group.
    • 
                    
  • Band input, ↑ ↓ - + — edit a component carrier's band, reorder, remove, or add another band to the combo.
    • 
                    
  • DL / UL feature dropdowns, - + — assign or remove feature sets (MIMO/bandwidth class) per carrier direction.
    • 
                    
  • Checkbox (per row) — selects this combo for the bulk actions above.
    • 
                    
  • JSON / Copy / Remove (per row) — edit this combo as raw JSON, duplicate it, or delete it.
